# Edge TTS Audio Generator

Небольшой Python-инструмент для последовательной генерации отдельных MP3-файлов из TXT, Markdown, FB2 и FB2.ZIP. Единственный движок озвучки — Microsoft Edge TTS через пакет `edge-tts`; локальные нейросетевые модели и GPU не требуются.

## Возможности

- рекурсивная обработка TXT, MD, Markdown, FB2 и FB2.ZIP;
- сохранение структуры каталогов и автоматическая нумерация MP3;
- именованные блоки `# Название` и разделители `#`;
- определение глав FB2 по XML-секции и заголовкам;
- алгоритмическое разделение длинных текстов без LLM;
- разбиение TTS-текста по предложениям и словам;
- ограниченные повторы Edge TTS с увеличивающейся задержкой;
- проверка каждого фрагмента и итогового MP3 через FFprobe/FFmpeg;
- JSON-манифесты для безопасного повторного запуска;
- восстановление отсутствующих, повреждённых или устаревших MP3;
- анализ глав без генерации аудио и ручной review-процесс.

## Установка

Требуется Python 3.12 или новее, доступ в интернет и FFmpeg с `ffmpeg.exe` и `ffprobe.exe` в `PATH`.

```powershell
python -m pip install -r requirements.txt
```

Для разработки и тестов:

```powershell
python -m pip install -r requirements-dev.txt
```

## Запуск

Поместите личные документы во входную папку, указанную в `config.toml`, и выполните:

```powershell
python main.py
```

Или используйте Windows-обёртку:

```powershell
.\start.bat
```

Примеры:

```powershell
python main.py --engine edge
python main.py --voice ru-RU-DmitryNeural --rate=-5%
python main.py --only "История\Лекция 1.md"
python main.py --only "Книга.fb2" --only-block 2
python main.py --max-chars 500
python main.py --dry-run
python main.py --check
```

Параметры голоса и скорости можно изменить через CLI или `config.toml`. Движок всегда Edge TTS; переключения на Piper, Silero или другие движки нет.

## Формат входных документов

TXT и Markdown поддерживают блоки:

```text
# Первая запись
Текст первой записи.

# Вторая запись
Текст второй записи.
```

Отдельная строка `#` также является разделителем. Символ `#` внутри обычной строки не разделяет текст. В Markdown заголовки первого уровня используются как границы глав. В TXT распознаются `Глава 1`, `Часть I`, `Пролог`, `Эпилог`, `Введение` и `Заключение`.

FB2 обрабатывается по XML-структуре `<section>` и `<title>`. FB2.ZIP читается без распаковки в пользовательские каталоги.

Безопасные демонстрационные файлы находятся в [examples](examples/).

## Режимы глав

```powershell
python main.py --analyze-only --chapter-mode rules
python main.py --analyze-only --chapter-mode auto
python main.py --review-chapters
python main.py --apply-review
```

`rules` использует явную структуру документа. `auto` дополнительно делит длинный текст по границам абзацев и приблизительному лимиту слов. Это обычные детерминированные правила, не семантический ИИ-анализ. Review-файл может менять заголовки, но не исходный текст.

## Повторный запуск и диагностика

Манифест рядом с результатами хранит хеши текста и параметров Edge TTS. Корректные актуальные файлы пропускаются. Отсутствующие или повреждённые записи создаются заново.

Журнал находится в `logs/generation.log`. Ошибка `NoAudioReceived`, HTTP 403 или недоступность Edge TTS фиксируются явно. Повторы ограничены; программа не пытается обходить ограничения Microsoft и не подменяет голос локальной моделью. При ошибке одного блока остальные документы продолжают обрабатываться.

## Тесты

```powershell
pytest -q
```

Тесты не требуют доступа к Edge TTS: сетевой слой моделируется. Реальную проверку можно выполнить отдельно на небольшом документе с `--engine edge`; итоговый MP3 рекомендуется дополнительно прослушать.
